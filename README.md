# ✈️ TravelGo Website

## Overview
TravelGo is a simple travel website created as part of a **Web Designing Assignment**.  
It helps users explore travel destinations, services, and packages.  
The website consists of two main pages:  
- `index.html` (Homepage)  
- `plans.html` (Services/Plans Page)

---

## Features

### 1. Homepage (`index.html`)
- Website branding with **TravelGo header** and navigation menu.  
- Introduction to TravelGo and its travel services.  
- Link to the Services/Plans page.  
- **Snapshots section** showcasing travel destinations with images and descriptions.  
- **Travel Terms section** explaining common travel-related terminology.  
- Contact information in the footer.

### 2. Services/Plans Page (`plans.html`)
- Overview of **Top 5 Travel Plans** (Rishikesh, Darjeeling, Varanasi, Goa, Rajasthan).  
- **Tour Packages Table** with duration, price, and highlights.  
- **Travel Essentials List** included in all packages.  
- Contact information in the footer.

## How to Run
1. Download the project files.  
2. Place them in a folder (e.g., `TravelGo`).  
3. Open `index.html` in any web browser.  
4. Use the navigation bar to explore other pages.
